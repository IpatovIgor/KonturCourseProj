# Трекер привычек

React-приложение для существующего API KonturCourseProj. Нужны Node.js 22.13 или новее в ветке 22.x либо Node.js 24 LTS и npm.

## Запуск

1. Запустите бэкенд через существующий профиль `http` на `http://localhost:5160`. Перед запуском задайте `JwtSettings__Secret` с приватным ключом длиной от 32 байт и `MongoDbSettings__ConnectionString` с адресом MongoDB replica set. Репликация нужна для создания привычек и записи отметок.
2. Из папки `habit-frontend` выполните:

   ```sh
   npm ci
   npm run dev
   ```

3. Откройте `http://localhost:5173`. После регистрации приложение выполнит вход и откроет список «Сегодня».

Vite проксирует `/api` на бэкенд и при разработке, и в режиме preview. Если сервер запущен на другом адресе, укажите его в `API_PROXY_TARGET` в файле `.env.local` или в окружении процесса Vite. По умолчанию клиент использует относительный путь `/api`. При размещении готовой сборки настройте проксирование `/api` на хосте фронтенда. Если API доступен с отдельного разрешённого сервером origin, задайте его полный базовый адрес, включая `/api`, через `VITE_API_BASE_URL` при сборке.

## Проверки

```sh
npm test
npm run lint
npm run build
npm run preview
```

Автоматические тесты проверяют интерфейс и HTTP-контракты с подменой транспорта Axios. Для сквозной проверки с тестовым аккаунтом зарегистрируйтесь, создайте ежедневную привычку, поставьте и снимите отметку, измените расписание, откройте историю и статистику, затем архивируйте привычку и проверьте её во вкладке «Архив».
