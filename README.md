# Трекер привычек

Локальный стенд запускает React, WebAPI, Worker, Notifications, MongoDB replica set и RabbitMQ. Интерфейс, API и SignalR доступны по одному адресу [localhost:8080](http://localhost:8080).

## Запуск

Нужен Docker с плагином Compose. Из корня скопируйте `.env.example` в `.env` и задайте разные случайные значения для `HABIT_TRACKER_JWT_SECRET`, `HABIT_TRACKER_WORKER_KEY` и `HABIT_TRACKER_RABBIT_PASSWORD`. В PowerShell 7 каждое значение можно сгенерировать командой `[Convert]::ToHexString([Security.Cryptography.RandomNumberGenerator]::GetBytes(32))`. Используйте те же значения при следующих запусках с сохранёнными томами.

```sh
docker compose up -d --build --wait
docker compose ps
```

`docker compose down` останавливает стенд и сохраняет локальные тома. Стенд слушает только `127.0.0.1`. MongoDB и RabbitMQ доступны внутри сети Compose. Профиль стенда использует три отдельные MongoDB-базы на одном узле и отключает ежедневную сводку (`HABIT_TRACKER_DAILY_SUMMARY_ENABLED=false`).

## Проверка напоминаний

1. Зарегистрируйтесь и создайте ежедневную привычку. Включите напоминание и выберите ближайшую будущую минуту в часовом поясе аккаунта. Пояс указан на экране «Сегодня».
2. Оставьте вкладку открытой. Откройте «Уведомления» и дождитесь записи. Повторите проверку с привычкой, отмеченной выполненной до заданной минуты. Запись для неё должна отсутствовать.
3. Снимите отметку у другой привычки до её времени и проверьте доставку. Перечитайте историю уведомлений после перезагрузки страницы. Должна остаться одна запись на привычку и дату.

Регрессионные тесты бэкенда запускаются на отдельной инфраструктуре по [инструкции](docs/webapi-testing.md). Для фронтенда из `habit-frontend` выполните `npm ci`, `npm test`, `npm run lint` и `npm run build`.
